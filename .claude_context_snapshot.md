## 1. AgentState 完整 Schema (`backend/src/graph/state.py`)

### AgentState (TypedDict)

| 字段 | 类型 | 用途 | 多领域隔离 |
|---|---|---|---|
| `messages` | `Annotated[Sequence[BaseMessage], add_messages]` | 对话历史，LangGraph 自动追加 | 通用 |
| `intent` | `str` | router 分类结果: `chat` / `rag` / `tool` / `structured_telecom_query` | **关键分流字段** |
| `intent_reasoning` | `str` | LLM 分类理由 | 可观测 |
| `rewritten_queries` | `list[str]` | Multi-Query 重写后的 3 个检索查询 | RAG 检索层 |
| `retrieved_docs` | `list[dict]` | ChromaDB 检索命中（去重合并后） | RAG 检索层 |
| `graded_docs` | `list[dict]` | LLM 相关性评分后的文档 | RAG 评分层 |
| `web_results` | `str` | 外网搜索回退结果（DuckDuckGo） | RAG 回退层 |
| `pending_sql` | `str` | NL→SQL 节点生成的 SQL，供 HITL 审批 | **Text-to-SQL 审批链路** |
| `pending_sql_reasoning` | `str` | LLM 生成 SQL 的推理说明 | HITL 审批展示 |
| `sql_query_result` | `str` | execute_sql_tool 查表结果（JSON） | **多领域 SQL 数据源** |
| `hallucination_score` | `float` | HallucinationCheck 输出 (0-1) | 质量闭环 |
| `hallucination_detail` | `str` | 逐句事实核查反馈 | 可观测 |
| `loop_count` | `int` | 检索-核查循环次数（最大 2） | 防御上限 |

### Pydantic Structured Output Schema

- **RouterOutput**: `intent: str` + `reasoning: str`
- **RewriteOutput**: `queries: list[str]` (3 个)
- **GradeOutput**: `relevance: "relevant"|"not_relevant"` + `score: float[0,1]`
- **HallucinationOutput**: `score: float[0,1]` + `feedback: str`
- **TextToSQLOutput**: `sql: str` + `reasoning: str`

### 多领域隔离机制

`intent` 字段区分领域，`pending_sql` / `sql_query_result` 跨领域通用：
- 电信气象 → router 输出 `structured_telecom_query` → 调用 `query_telecom_weather_db`
- 企业制度 → 同 intent → `execute_sql_tool` 多工具 fallback → 自动匹配 `query_enterprise_policy_db`
- 新增领域只需在 `mcp_databases.json` 添加工具配置

## 2. StateGraph 拓扑路由逻辑 (`backend/src/graph/builder.py` + `edges.py`)

### 节点清单 (10 个, 全部串行, 无并行节点)

| 节点 | 工厂函数 | 注入依赖 | 作用 |
|---|---|---|---|
| `router` | `create_router_node(model)` | LLM | 意图分类 |
| `text_to_sql` | `create_text_to_sql_node(model)` | LLM | NL→SQL 生成 |
| `execute_sql_tool` | `create_execute_sql_tool_node(db_tools)` | MCP tools[] | SQL 执行 (多工具 fallback) |
| `rewrite` | `create_rewrite_node(model)` | LLM | Multi-Query 重写 |
| `retrieve` | `create_retrieve_node(retrieve_func)` | RAGFacade | ChromaDB 多路检索 |
| `grade` | `create_grade_node(model)` | LLM | 文档相关性评分 |
| `web_search` | `create_web_search_node(search_func)` | DuckDuckGo | 外网回退 |
| `tool_execute` | `create_tool_execute_node(model, data_tools)` | LLM + tools | 数据分析/绘图 |
| `generate` | `create_generate_node(model)` | LLM | 多源融合生成 |
| `hallucination_check` | `create_hallucination_check_node(model)` | LLM | 事实核查 |

### 路由拓扑 (ASCII)

```
__start__
    │
    ▼
[router] ──────────────────────────────────────────┐
    │                                               │
    ├── intent=structured_telecom_query              │
    │     ▼                                          │
    │  [text_to_sql] ──固定边──► [execute_sql_tool]  │
    │     ▲                        │                 │
    │     │                   ⏸ HITL interrupt_before │
    │     │                        │                 │
    │     └── (retry via rewrite)  │                 │
    │                              ▼                 │
    ├── intent=rag ──────────► [rewrite]             │
    │                              │                 │
    │                              ▼                 │
    │                          [retrieve]            │
    │                              │                 │
    │                              ▼                 │
    │                           [grade]              │
    │                          ┌───┴───┐             │
    │                    relevant   irrelevant       │
    │                          │       │             │
    │                          │  [web_search]       │
    │                          │       │             │
    │                          └───┬───┘             │
    │                              ▼                 │
    ├── intent=chat ─────────► [generate] ◄──────────┘
    │                              │
    │                              ▼
    │                     [hallucination_check]
    │                          ┌───┴───┐
    │                      通过      不通过
    │                     (END)    (回rewrite, ≤2轮)
    │
    └── intent=tool ──► [tool_execute] ──► END
```

### 条件边汇总 (`edges.py`)

| 函数 | 判断依据 | 输出分支 |
|---|---|---|
| `route_intent` | `state["intent"]` | `text_to_sql` / `rewrite` / `tool_execute` / `generate` |
| `grade_documents` | `state["graded_docs"]` 中是否有 `relevance=="relevant"` | `generate` / `web_search` |
| `check_hallucination` | `state["hallucination_score"]>=0.6` 或 `loop_count>=2` | `generate(END)` / `rewrite` |

### HITL 断点

- `interrupt_before=["execute_sql_tool"]` (当 db_tools 非空时自动启用)
- `interrupt_before=["tool_execute"]` (通过 hitl/approvals.py 策略配置)
- Resume: `POST /chat/resume {"session_id":"...","approved":true}` → `graph.ainvoke(None, config)`

```sql
    summer_temp     REAL,               -- 夏季气温 (℃)
    autumn_temp     REAL,               -- 秋季气温 (℃)

);
```

## 4. Git 工作流规范

### 远程仓库

| Remote | URL | 用途 | 状态 |
|---|---|---|---|
| `origin` | `Yezhe-Liu/DataAgent.git` | 私有开发仓库 | 不活跃 |
| `release` | `Yezhe-Liu/DataAgent-Release.git` | 公开稳定发布 | **活跃** |

### 分支策略

```
本地 dev (30+ 开发 commits)  ──squash──► 本地 master ──push──► release/master
    ↑                                                             │
    └── 日常开发                                                  └── 面试官只看到 5 个结构化 commit
```

### 常用命令

```bash
# 日常开发
git checkout dev
git add -A && git commit -m "feat/fix: ..." && git push origin dev  # 私有仓库

# 发布稳定版本到公开仓库
git checkout master
# ... 将 dev 的新功能 squash 合并到 master ...
git push release master

# 紧急修复: 直接在 master 修改, 然后同步回 dev
git checkout master
# ... 修复 ...
git push release master
git checkout dev && git cherry-pick <fix-commit>
```

### Commit 规范

- 前缀: `feat:` / `fix:` / `docs:` / `chore:`
- 每条 Co-Authored-By: Claude Opus 4.7
- 公开仓库 commit message 使用中文技术术语，不暴露开发过程
